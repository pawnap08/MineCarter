Enabling cheats

  1. open settings
  2. press the alt button
  3. keep pressing alt and type in "criminell"
  4. release alt, "cheats enabled" should appear in the top left corner

Cheat codes

  1. Ctrl+S hold: noclip
  2. Shift+S hold: insta-mine
  3. Shift+Ctrl hold: insta-buy
  4. Shift+R: insta-paycheck
  5. Alt+Plus: add +1 to selected inventory item

Resetting progress

  1. go to tile screen
  2. open settings
  3. press the alt button
  4. keep pressing alt and type in "reset"
  5. release alt, "progress reset" should appear in the top left corner
  6. quit and reopen the game
